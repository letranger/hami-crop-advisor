# 開發歷程簡報

兩個版本，各 27 張（開發故事 15 張＋技術細節 12 張），每頁附講稿：

| 資料夾 | 內容 |
|---|---|
| `正式版/` | 八個開發步驟的正式簡報，中段插入「技術細節」章：拿 API 金鑰（Groq、Google AI Studio、Tavily）、推上 GitHub、Vercel 匯入與環境變數、藏鑰匙三道保險、手冊＋網路搜尋如何交給 Groq 合寫 |
| `卡通版/` | 同一個故事，用卡通人物（雲龍師、我、Claude、Gemini、Groq）串場；同樣內容的技術章改名「幕間：技術幕後大公開」 |

每個資料夾內：

- `index.html`：用瀏覽器打開即可播放。← → 換頁、N 顯示講稿、F 全螢幕
- `*.pdf`：可直接列印或離線播放
- `images/`：簡報用到的圖片（含各服務後台的真實截圖，金鑰都只露頭尾）
- `source/`：原始投影片檔（Claude Slides 格式），之後要改內容用
