存程式 ① 送上 GitHub

五行指令，但我們是用一句話叫 Claude 做

git init

git add .

git commit -m "初始化 PWA 雛形"

git remote add origin https://github.com/letranger/hami-crop-advisor.git

git push -u origin main

實際對 Claude Code 說的是：「幫我 commit 並 push 到 GitHub」。指令是它打的，我們只看結果。

github.com/letranger/hami-crop-advisor：公開儲存庫，右側 About 直接連到正式網站

事前：到 github.com 註冊、New repository 建一個空的，取好名字

技術細節 4 / 12

第二件事，把程式送到 GitHub。技術上就是左邊這五行：init 建倉庫、add 把檔案加進去、commit 寫一句說明、remote add 指定 GitHub 上的網址、push 推上去。但我們沒有自己打，是對 Claude Code 說「幫我 commit 並 push 到 GitHub」，它會自己打指令，我們看結果就好。事前要做的只有到 github.com 註冊，然後 New repository 建一個空的倉庫。我們實際卡過一關：第一次 push 會問密碼，但 GitHub 現在不收密碼了，要用 gh auth login 用瀏覽器登入一次，之後就都不用再問。右邊就是倉庫在 GitHub 上的樣子。
