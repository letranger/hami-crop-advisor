架網站 ① GitHub 的程式碼怎麼變成網址

Vercel：用 GitHub 帳號登入，匯入儲存庫，按 Deploy

1 · 登入

vercel.com → Continue with GitHub，Vercel 才看得到你的儲存庫

2 · 匯入

Add New → Project，找到 hami-crop-advisor 按 Import

3 · 設定

Framework 選 Other（純靜態＋api/）；Root Directory 維持根目錄

4 · Deploy

一分鐘後得到 hami-crop-advisor.vercel.app

Deployments 頁：一筆 commit ＝ 一次部署，建置 7～14 秒，最新一筆就是正式站

Vercel 怎麼知道程式改了？

匯入時 Vercel 在 GitHub 裝一個「通知」：main 一有新 commit 就重新部署。右邊每一列的 commit 代號和 GitHub 上的一模一樣。

專案裡的 vercel.json

只做兩件事：網址去掉 .html；執行 api/ 時把 kb.json（知識庫）一起帶著。

技術細節 6 / 12

第三件事，把 GitHub 上的程式碼變成一個網址，這是 Vercel 的工作。四步：到 vercel.com 用 GitHub 帳號登入，一定要用 GitHub 登入，Vercel 才看得到你的儲存庫；Add New、Project，清單裡找到 hami-crop-advisor 按 Import；設定頁 Framework 選 Other，因為我們是純靜態網頁加 api 資料夾，不是什麼框架；最後按 Deploy，一分鐘後就拿到 hami-crop-advisor.vercel.app 這個網址。下面是我們專案真實的 Deployments 頁面，每一列就是一次部署，對應 GitHub 上的一筆 commit，代號一模一樣，建置只要 7 到 14 秒，最上面標 Production 的就是現在農友用的版本。匯入時 Vercel 會在 GitHub 裝一個通知，之後 main 分支一有新 commit 就自動重新部署，這就是前一張綠色勾勾的來源。專案裡的 vercel.json 很短，只有兩個設定：網址去掉 .html，還有執行 api 時要把知識庫 kb.json 一起帶著。
