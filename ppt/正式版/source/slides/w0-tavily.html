app.tavily.com → Overview 往下捲就是 API Keys；按「＋」建新的，眼睛圖示看全文，複製圖示複製

申請

Google 帳號登入即可，免信用卡；金鑰 tvly- 開頭

額度

免費每月 1,000 次搜尋；問過的問題有快取，實際用不到

設定

Vercel 環境變數加一列 TAVILY_API_KEY，Redeploy

為什麼不直接用 Google？

Google 搜尋回傳的是「給人看的網頁」：標題、網址、一小段摘要。要給 AI 讀還得自己再去抓每一頁、清掉廣告和選單。

Tavily 一次就回傳每個結果的正文片段，程式一行就能貼給模型。Google 自家的 Custom Search API 也要綁 Google Cloud 專案和信用卡，對學生專案太重。

技術細節 10 / 12 · 金鑰名稱 TAVILY_API_KEY · 程式位置 api/_rag.js webSearch()

很多人問，App 的「上網查」是不是接 Google 搜尋？不是，我們用的是 Tavily，一個專門給 AI 用的搜尋 API。申請方式和前面一樣：app.tavily.com 用 Google 帳號登入，免信用卡，Overview 頁往下捲就是 API Keys，按加號建一把，金鑰是 tvly 開頭，眼睛圖示可以看全文，複製後到 Vercel 環境變數加一列 TAVILY_API_KEY，Redeploy。免費額度每月一千次搜尋，加上同樣的問題有快取，實際用不到。為什麼不直接用 Google？因為 Google 搜尋回傳的是給人看的網頁清單，標題、網址、一小段摘要，要給 AI 讀還得自己去抓每一頁、清掉廣告和選單；Tavily 一次就回傳每個結果的正文片段，程式一行就能貼給模型。Google 自己的 Custom Search API 也要綁 Google Cloud 專案和信用卡，對學生專案太重。
