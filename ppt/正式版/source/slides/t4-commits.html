之後每次修改也是一樣的動作。這是 GitHub 的 Commits 頁面，每一筆都有一句中文說明，三個月後回頭看也看得懂。作者寫著 letranger and claude，因為 Claude Code 會把自己也簽上去。注意每筆後面的綠色勾勾，那是 Vercel 回報這一筆已經成功部署，如果是紅叉就代表上線失敗，要回去看錯誤。所以整個流程就是：改好程式、commit 加 push 到 main 分支、Vercel 自動偵測到，30 到 60 秒後網站就是新版，農友手機重新整理就看到了。這個「推上去就自動上線」是下一張要講的 Vercel 設定。
