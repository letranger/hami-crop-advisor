房東 ①：Vercel 把程式變成網址

1 登入

vercel.com → Continue with GitHub（房東才看得到保險箱）

2 匯入

Add New → Project → 找到 hami-crop-advisor → Import

3 設定

Framework 選 Other；Root Directory 維持根目錄

4 Deploy

一分鐘後得到 hami-crop-advisor.vercel.app

Deployments 頁 · 一筆 commit＝一次上架，7～14 秒，最上面標 Production 的就是正式站

Framework 要選什麼？
清單一大堆英文……

選 Other。我們是純網頁加 api 資料夾，不是什麼框架。

技術幕後 6 / 12 · 匯入時 Vercel 在 GitHub 裝了「通知」，main 一有新 commit 就重新上架

房東第一步，Vercel 把 GitHub 的程式變成網址。四步：用 GitHub 帳號登入 vercel.com，一定要用 GitHub 登入房東才看得到保險箱；Add New、Project，找到 hami-crop-advisor 按 Import；設定頁 Framework 選 Other，我問 Claude 清單一大堆英文要選哪個，它說選 Other，因為我們是純網頁加 api 資料夾；最後按 Deploy，一分鐘後拿到網址。下面是真實的 Deployments 頁，一筆 commit 就是一次上架，只要 7 到 14 秒，最上面標 Production 的就是現在農友用的版本。匯入時 Vercel 會在 GitHub 裝一個通知，之後 main 一有新 commit 就自動重新上架。
