技術幕後 10 / 12 · 程式裡的名字：TAVILY_API_KEY · 位置 api/_rag.js webSearch()

雲龍師問：App 的上網查是接 Google 搜尋嗎？不是，是 Tavily，專門給 AI 用的搜尋 API。申請方式和前面一模一樣：app.tavily.com 用 Google 登入，Overview 往下捲就是 API Keys，按加號建一把，tvly 開頭，複製後到房東那邊加一列 TAVILY_API_KEY 再 Redeploy。免費每月一千次，加上快取根本用不到。為什麼不用 Google？Google 搜尋回傳的是給人看的網頁清單，AI 要讀還得自己抓每一頁、清廣告；Tavily 一次就回傳每筆的正文片段，一行就能貼給模型。Google 自家的 Search API 還要綁 Cloud 專案和信用卡，學生專案太重。
