保險箱 ①：把程式送上 GitHub

git init

git add .

git commit -m "初始化 PWA 雛形"

git remote add origin https://github.com/letranger/hami-crop-advisor.git

git push -u origin main

github.com/letranger/hami-crop-advisor · 右邊 About 直接連到正式網站

事前：github.com 註冊、New repository 建一個空的

卡關：第一次 push 問密碼，GitHub 早就不收密碼，要先 gh auth login

我只打一句：
「幫我 commit 並 push」

五行指令我來打，
你看結果就好……

技術幕後 4 / 12 · 第九幕「程式推不上 GitHub」就是這個卡關

保險箱第一步，把程式送上 GitHub。技術上是左邊五行指令：init、add、commit、remote add、push。但我只打一句「幫我 commit 並 push」，Claude 會自己打指令，我看結果就好。事前只要到 github.com 註冊、New repository 建一個空的。我們實際卡過一關：第一次 push 問密碼，但 GitHub 早就不收密碼，要先用 gh auth login 用瀏覽器登入一次。右邊就是倉庫在 GitHub 上的樣子，About 直接連到正式網站。
